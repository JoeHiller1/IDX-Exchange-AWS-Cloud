The root user has more admistrative power than the IAM user because it can control and delete all account information and data. The IAM user is better for everyday tasks because it can only use the permissions granted to it and is therefore safer. MFA should be used to protect the root user because the root user has great power over the account. The shared responsibility model ensures that users protect the security of what they put into the cloud itself, while AWS manages the security of its services and infrastructure. Shared responsibility applies to IAM because when running everyday tasks, it is important to secure the data and code that is put into the cloud. It also applies to securing the root user through tactics such as MFA.
